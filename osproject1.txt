Επίσης 

Το πρόγραμμα μεταγλωτίζεται και τρέχει ως εξής σε terminal:
- make all
Αυτή η εντολή μεταγλωτίζει όλα τα αρχεία (seperate compilation).
- ./final -f <file> -b <int> -m <int>
Οι σημαίες μπορούν να είναι και με διαφορετική/τυχαία σειρα.
- make clean 
Η make clean διαγράφει όλα τα ".o" αρχεία. 

Παραδοχές:

- Έχω κάνει την παραδοχή οτι τα δεομένα στα αρχεία με τουσ voters είναι με την εξής σειρά:
1ο είναι το PIN, δεύτερο είναι το επίθετο, 3ο είναι το μικρό όνομα και 4ο είναι ο ταχυδρομικός κώδικας.

- Έχω κάνει την παραδοχή οτι όλα τα ονόματα είναι πάντα με κεφαλαία γράμματα αγγλικού αλφαβήτου.

Παρατηρήσεις:

- Έχω προσθέσει μια ακόμα σημαία/παράμετρο γραμμής εντολών,την "-m" η οποία ονοματίζει τον αρχικό αριθμό των buckets 
που θα υπαρχουν στο hash table. Η παράμετρος που ακολουθεί αυτή τη σημαία πρέπει να είναι integer.

- Από κάθε αρχείο τα δεδομένα διαβάζονται με τη χρήση της συνάρτησης fgets(). Το buffer length για την fgets() το έχω ορίσει
ως μια const int μεταβλητή μεγέθους 255.

- Στο prompt το input διαβάζεται επίσης με τη χρήση της συνάρτησης fgets() στην οποία το buffer length είναι πάλι ορισμένο ως
μια const int μεταβλητή μεγέθους 255.

- Το μέγεθος των string για το όνομα και το επίθετο κάθε ελέκτορα είναι ορισμένο ως μία const int μεταβλητή μεγέθους 255.

- Στο hash table το load factor threshold είναι ορισμένο ως μία const float μεταβλητή μεγέθους 0.75.

Συνοπτική Επεξήγηση Κώδικα:

1. Elector class: Είναι η κλάση για τους ελέκτορες και περιέχει όλα τα στοιχεία που χρειάζεται κάθε ελέκτορας.

2. InputFile: Είναι μια κλάση η οποία διαβάζει το input file (το file που δώθηκε στα command line arguments), 
δημιουργεί για κάθε γραμμή του file ένα pointer σε Elector class object και στη συνέχεια τα εισάγει στο hash table.

3. Linear Hash Table:
To linear hash table που έχω υλοποιήσει αποτελέιται από τα εξής στοιχεία. Ένα struct Bucket που αντιπροσωπεύει το κάθε bucket.
Περιέχει έναν πίνακα στον οποίο αποθηκεύονται pointers σε Elector class objects και ένα pointer που δείχνει στο επόμενο bucket (ovewrflow bucket).
To hash table είναι ένα struct (struct LinearHashTable) το οποία περιέχει ένα πίνακα, τα στοιχεία του οποίου είναι pointers σε struct Bucket. 
Επίσης περιέχει κ άλλες χρήσιμες μεταβλητές για τη λειτουργία του hash table.
Η συνάρτηση εισαγωγής στοιχείου (InsertKey()) στο hash table λειτουργεί ως εξής: Παίρνουμε το hash χρησιμοποιώντας τη hash function 1,
αν το index του bucket στο οποίο δείχνει ο pointer είναι μεγαλύτερο από το hash τότε χρησιμοποιούμε τη hash function 2 για να εισάγουμε το 
στοιχείο στο hash table χρησιμοποιώντας την AddKey() ενώ πρώτα γίνεται έλεγχος για το αν χρειάζεται να εισάγουμε overflow bucket χρησιμοποιώντας.
τη CheckOverflow(). Στη συνέχεια ελέχουμε αν το load factor είναι μεγαλύτερο από το load factor threshold και αν είναι τότε πρέπει να κάνουμε
split το bucket στο οποίο δείχνει ο pointer. Αν το bucket που πρέπει να γίνει split έχει ένα ή παραπάνω overflow buckets τότε χρησιμοποιούμε
τη συνάρτηση SplitOverflowBucket() αλλιώς τη συναρτηση SplitBucket(). Στη συνέχεια ο pointer μετακινείται μια θέση πιο "κάτω" στο hash table.
Τέλος μετά το split ελέγχουμε αν μπήκαμε σε νέο round.

Τι κάνουν μερικές από τις συναρτήσεις :

SplitBucket(): Κάνει split ένα bucket το οποίο δεν έχει overflow buckets. Χρησιμοποιεί την InsertNewBucket() για να βάλει ένα καινούριο
bucket στο table και στη συνέχεια αναδιανέμει τα στοιχεία με βάση το hash function 2. Πρίν είσαγει κάθε στοιχείο ξανα ελέγχει αν χρειάζεται
overflow bucket.

SplitOverflowBucket(): Κάνει split ένα bucket το οποίο έχει ένα ή παραπάνω overflow buckets. Χρησιμοποιεί την InsertNewBucket() για να βάλει ένα καινούριο
bucket στο table και στη συνέχεια κάνει iterate σε όλα τα overflow buckets και αναδιανέμει τα στοιχεία με βάση το hash function 2. Πρίν είσαγει κάθε στοιχείο ξανα ελέγχει
αν υπάρχει θέση κενή για το στοιχείο χρησιμοποιώντας την CheckForSpot() αλλίως εισάγει overflow bucket. Στη συνέχεια διαγράφει και αποδεσμεύει
μνήμη για τα κενά overflow buckets που έχουν απομείνει με τη DeleteEmptyOverflowBuckets().

DeleteEmptyOverflowBuckets(): Διαγράφει και και αποδεσμεύει μνήμη για τα κενά overflow buckets που έχουν απομείνει μετά από το split.
Αν διαγραφτεί το πρώτο overflow bucket τότε σημαίνει οτι θα διαγραφούν και τα υπόλοιπα διότι τα στοιχεία έχουν πάει σε buckets με άλλο index
number οπότε κάνει το next του primary bucket να είναι ίσο με NULL.

CheckForSpot(): Ελέγχει αν υπάρχει κενή θέση στο primary bucket ή στα overflow του που εμπρόκειται να εισαχθεί το στοιχείο και αν χρειάζεται να εισαχθεί overflow bucket. 
Χρησιμοποιείται μόνο από τη SplitOverflowBucket() για περιπτώσεις όπως όταν τα περισσότερα από τα στοιχεία ξανα εισάγονται στο ίδιο bucket μερά από το split.
CheckOverflow(): Είναι σαν την CheckForSpot(), δηλαδή ελέγχει αν υπάρχει κενή θέση στο primary bucket που εμπρόκειται να εισαχθεί το στοιχείο και αν χρειάζεται 
να εισαχθεί overflow bucket, αλλα χρησιμοποιείται μόνο από τη SplitBucket().

AddKey(): Εισάγει το στοιχείο στο hash table σύμφωνα με το hash που δέχεται σαν όρισμα.

4. Reverse Index: Αυτή η δομή αποτελείται από τα εξής στοιχεία. Αρχικά ένα struct ElectorListNode που αντιπροσωπεύει έναν κόμβο της εσωτερικής συνδεδεμένης λίστας,
δηλαδή της λίστας που περιέχει pointers σε Elector class objects και ένα pointer στον επόμενο κόμβο, δηλαδή αποθηκεύει τους Electors. Το struct RevIdxNode αντιπροσωπεύει 
έναν κόμβο της δομής ανεστραμμένου κατάλογου και περιέχει έναν int που είναι ο ταχυδρομικός κώδικας, ένα int που είναι το μέγεθος της εσωτερικής λίστας αυτού του κόμβου
ένα pointer σε struct ElectorListNode που δείχνει στην αρχή της εσωτερικής λίστας του κόμβου και ένα struct RevIdxNode pointer που δείχνει στον επόμενο κόμβο του ανεστραμμένου
κατάλογου. Τέλος, ένα struct ReverseIndex το οποίο περιέχει ένα struct RevIdxNode pointer ο οποίος δείχνει στον πρώτο κόμβο του ανεστραμμένου κατάλογου και ένα int το οποίο είναι
το συνολικό πλήθος των Electors που υπάρχουν μέσα στον κατάλογο.
Οι συναρτήσεις είναι απλές και εξηγούνται με comments.


5. Prompt:

Τι κάνουν μερικές συναρτήσεις:

PromptLoop(): Χειρίζεται το prompt loop, δέχεται το input του χρήστη και αντιδρά αναλόγως. Ελέγχει αν το command που έδωσε ο χρήστης είναι σωστό,
αν έχει τον σωστό αριθμό από παραμέτρους/σημαίες και αν οι παράμετροί του κάθε command είναι σωστού τύπου. Αν περάσει όλους τους παραπάνω ελέγχους,
τότε εκτελεί τις εντολές. Το loop τελειώνει όταν ο χρήστης πληκτρολογήσει την εντολή "exit". Αν ο χρήστης πατήσει μόνο enter, ή πολλά κενά/tabs και
μετά enter τότε απλά αλλάζει γραμμή δηλαδή ξαναγυρνάει στην αρχή του loop. Αν ο χρήστης πληκτρολογήσει ένα command το οποίο δεν υπάρχει τότε ανάλογο 
μήνυμα εμφανίζεται στην οθόνη. Αν ο χρήστης πληκτρολογήσει σωστό command αλλά με λάθος αριθμό παραμέτρων ή με λάθος τύπο παραμέτρων τότε σχετικό
μήνυμα εμφανίζεται στην οθόνη. Στα single commands δηλαδή τα commands τα οποία δεν έχουν παραμέτρους/flags αφού ελεγχθεί οτι το command που έδωσε ο χρήστης
είναι σωστό, χρησιμοποιείται η συνάρτηση CheckPlainCommand() η οποία ελέγχει αν το command είναι valid, δηλαδή αν στο input string περιέχεται μόνο
το command ως μια λέξη επιτρέποντας μόνο spaces/tabs πρίν ή μετά το command και προφανώς το '\0'. Δηλαδή αν υπάρχουν άλλοι χαρακτήρες εκτός από space/tab/'\0'
και το command ως μια λεξη και όχι διάσπαρτους χαρακτήρες τότε δεν είναι valid (π.χ. για το exit command, το "   exit     q" δεν είναι valid). 
Με παρόμοιο τρόπο λειτουργούν και τα commands τα οποία έχουν παραμέτρους. Για τον έλεγχο της εγκυρότητας των commands που έχουν παραμέτρους χρησιμοποιείται η
ExtractWords() η οποία παίρνει σαν παράμετρο το input string και εξάγει όλες τις λέξεις που υπάρχουν στο string και τις αποθηκεύει σε ένα πίνακα 
(λέξεις ενός string θεωρώ όλα τα substrings του αρχικού string που διαχωρίζονται από κενά ή tabs). Στη συνέχεια ελέγχει αν το πλήθος των λέξεων είναι σωστό για το 
συγκεκριμένο command (δηλαδή το command i αποτελείται από 5 λέξεις, το command το ίδιo και τις 4 παραμέτρους του). Δηλαδή για να είναι valid ένα command που 
έχει παραμέτρους πρέπει να έχει ακριβώς όσες παραμέτρους χρειάζεται. Στη συνέχεια γίνεται έλεγχος για κάθε παράμετρο ξεχωριστά και εμφανίζεται σχετικό μήνυμα αν
υπάρχει κάποιο λάθος με τις συναρτήσεις IsInt() που ελέγχει αν το string είναι integer και την IsAtoZstring() η οποία ελέγχει αν το string είναι κεφαλαία γράμματα 
αγγλικού αλφάβητου.

Το prompt έχει φτιαχτεί να αναγνωρίζει τα commands αν αυτά έχουν στην αρχή, στο τέλος ή ανάμεσα από το command και τα flags του 
spaces ή tabs. Για παράδειγμα, το exit command, αν ο χρήστης δώσει ως input "    exit        " δηλαδή σωστό command αλλά με
κενά πρίν και μετά το command το prompt θα το αναγνωρίσει και θα το πάρει ως σωστό command. Το ίδιο γίνεται και
στα commands τα οποία δέχονται σημαίες/ παραμέτρους. Δηλαδή αν υπάρχει κενό ή tab στην αρχή,το τέλος αλλά και ανάμεσα
από το command και τα flags του τότε το prompt θα το πάρει ως σωστό μόνο βέβαια αν είναι σωστά γραμμένο το command, και τα flags είναι σωστά.
Με λίγα λόγια έχει φτιαχτεί να αγνοεί όλα τα spaces ή tabs.

hash table στο terminal.
-pri : Αυτή η εντολή δεν παίρνει καμία παράμετρο ή σημαία και η λειτουργία της είναι να εκτυπώσει το
reverse index στο terminal.
-t : Αυτή η εντολή δεν παίρνει καμία παράμετρο ή σημαία και η λειτουργία της είναι να εκτυπώσει το
το πλήθος των ελεκτόρων που υπάρχουν συνολικά ανεξάρτητα με το αν έχουν ψηφίσει ή όχι στο terminal
(δηλαδή το πόσοι ελέκτορες υπάρχουν μέσα στο hash table).
